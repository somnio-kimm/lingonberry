# Concise cross-language translations

This edition replaces long definition fields with concise equivalents in eight English/Korean explanation packages. Study cores and English → English definitions are unchanged. See [meaning style](../../../docs/meaning-style.md).

- `release.json`: immutable source package paths/digests, source-file digests and new explanation versions.
- `nikl-equivalents.jsonl`: 23,931 selected entry/sense records with source Korean headwords/definitions and English equivalent/definition fields. Derived from the existing 19 June 2026 XML snapshot; the original file hashes, URLs and revision are in `../multilingual/broad-source-manifest.json`.
- `ja-editorial.jsonl`: 1,157 AI-assisted bilingual editorial exceptions, bound to the unchanged Japanese headword and previous English/Korean meanings. Brief register/sense qualifiers are retained. Native-speaker review is pending.
- `changes.jsonl` and `report.json`: generated before/after meaning changes, selection methods and counts. Existing per-entry provenance and example translation data are preserved.

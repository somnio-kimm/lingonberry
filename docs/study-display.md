# Study display

Word details and flashcard backs use one selected example. A reviewed bilingual primary example takes precedence; when none is available, the app chooses a source sentence, preferring a headword match and an available translation in the selected explanation language. English source translations are not shown as Korean explanations.

The detail sheet uses a single **Examples** heading and its speaker reads the selected sentence. Source provenance remains in the unchanged language packages and licence notices. This display fallback does not promote untranslated reference sentences into scored cloze, scramble or sentence-dictation exercises.

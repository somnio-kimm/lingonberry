# German, Chinese and Japanese entry review

The full review covers every entry's selected meaning, part of speech, reading or grammatical forms, example, English equivalent, Korean equivalent and both sentence translations. Cross-language meanings use concise equivalents; dictionary-style English definitions apply only to English learning through English. Existing German/Chinese/Japanese records are not expanded into the English per-sense card model during this pass.

Reviewers work through immutable `de-input.jsonl`, `zh-input.jsonl` and `ja-input.jsonl` under `local-data/coverage/four-language-review/`. Every input was compared with the current integrity-checked package bytes and every original `sourceDigest` recomputed. `non-english-review-manifest.json` records those bindings and preserves the earlier 240 Chinese and 80 Japanese decisions. These checkpoints do not establish full-list approval.

Use conversation agents for linguistic authoring and review. Local model inference and inference APIs remain disabled. Reading, hashing, parsing dictionaries and running application tests are ordinary tooling, not linguistic generation.

## Checkpoints and approval

Run with the repository's Node 26 toolchain:

```sh
node scripts/audit-language-entry-reviews.mjs
node scripts/audit-language-entry-reviews.mjs --require-complete
node --test tests/language-entry-review.test.mjs
```

Each primary decision binds the exact input, records the fields examined and explains retention or correction. Save atomically and calculate the actual missing-ID set on resumption. Preserve original source metadata and prior decisions. Never fill the journal with heuristic approvals based on field presence.

Every added or inherited additional example needs an explicit `additionalExamplesReviewed` acknowledgement and a matching, nonempty translation in each explanation's `additionalExampleTranslations` array. Put newly authored translations in `proposedEnglishExplanation` and `proposedKoreanExplanation`; a locale-keyed map on the decision itself is not consumed by package assembly.

The shared audit accepts the existing Chinese full-object proposal format and the German/Japanese field-review format. It separates primary review coverage from independently approved corrections and unresolved sources. Changed records require an independent `*-cross-review.jsonl` approval bound to the exact decision digest. Rejections and source findings block completion even when the primary reviewer retained an entry.

Independent `sourceIssues`/`usageIssues` and resolution objects with `required: true` are material gates even when the primary reviewer omitted them. An unresolved note without a scope flag blocks finalisation under `pendingScopeClassification`; the reviewer must distinguish a real content/practice uncertainty from an observation. Use `required: false` with an explicit reason only for a non-material observation, such as lack of a runtime certificate for an otherwise correct unchanged paradigm. That label cannot waive a primary or independent issue list. Classifying a note is not a new linguistic approval or a reason to blanket-repeat tests.

External source findings stay in `*-source-findings.jsonl`. An independent closure must cite the exact finding digests and supporting evidence; old approvals cannot hide a new source problem. Unclassified example metadata is an uncertainty, not proof of infringement. Contributor examples, publisher quotations and original new sentences must remain distinguished. Retained ShareAlike material and its translations keep compatible licences, source links and attribution.

Usage-representation findings stay separate from source uncertainties. For example, some official Chinese entries attach different parts of speech to different HSK levels. Preserve every verified official branch and its qualifiers; do not discard a valid meaning merely because the primary example uses another branch. An independent `usageResolution` is required before declaring the representation settled.

Known inherited `original-neutral-context-frame-v1` and `original-topic-context-v1` examples remain under `pendingExampleQuality`, including additional examples. Merely discussing or mentioning a headword does not demonstrate its selected meaning. Replace these frames with useful reviewed contexts and truthful component provenance; a source, grammar or generic approval cannot waive the frame. Original text and credits stay in private history. Explicit primary/independent `exampleQualityIssues` and scoped `exampleQualityResolution` use their own gate, separate from source and usage findings, with the same fresh independent binding and classification requirements. This check recognises known generators; it does not certify the quality of other sentences or reject all short examples.

The audit verifies coverage and evidence integrity. It cannot itself establish linguistic correctness or native-speaker certification. Do not mark a language complete or publish its revised package until all required entries, correction approvals, source closures and package checks are complete.

## Language-specific checks

- German: check articles, plurals, verb paradigms, cases and idiomatic translations. Preserve genuine Goethe vocabulary matches. Official grammar and communicative inventories can establish basic forms missing from standalone headword extraction; record that evidence separately. A plain article form is not automatically the same sense as a relative pronoun. Unmatched reference vocabulary stays in editorial B2–C2 groups. Preserve explicit null singular gender for plural-only entries; the German adapter must not derive feminine from plural die. Headings and saved words retain the plural number scope, with the existing article palette unchanged.
  Compound-tense answer inventories come from the active complete `forms.perfekt` alternatives (for example, `hat … / ist …`), not archived source paradigms or a preferred auxiliary label. Keep alternatives outside the selected word/sense scope in source metadata. Parser correctness alone does not approve context-specific sense eligibility.
  Leading subject-reflexive `sich` in constructed answers requires reviewed `reflexive_case: accusative` or `dative` (explicit source abbreviations `acc` and `dat` are also accepted); it is inflected for the requested person. Preserve independent bare/reflexive citations and already complete finite forms. FutureI uses declared slash-separated `infinitive` alternatives, or derives simple bare/reflexive templates from active perfect citations. A complex reflexive construction needs its explicit infinitive; missing/ambiguous case data withholds incomplete questions instead of guessing or dropping one active alternative.
  Word Input can accept explicitly reviewed core `aliases` through the same vocabulary engine, retaining every required noun article. Do not promote archived source spellings, related inflections or a different sense into aliases automatically; spelling equivalence and grammar remain separate review decisions. Explicitly reviewed `article_optional: true` allows a bare noun name and its declared full nominative alternatives in Word Input, including saved snapshots. Case and Cloze use the exact bare/full phrases in its declared inventories; adjective generation retains its article-bearing invariant. Ordinary nouns still require articles, and proper-noun spelling alone never enables this exception. German Cloze honours a validated explicit example focus before legacy form search, including inflected targets missing from a paradigm; invalid explicit spans do not silently choose another occurrence. Existing saved spans remain historical records. Inflected adjective distractors share the existing adjective stem/ending rules; when a target permits several grammatical analyses, a choice must fit all of them. Unsupported forms are withheld rather than filled with an uninflected adjective.
- Chinese: preserve official headword, citation pronunciation and level. Verify the example's selected polyphonic reading, contextual pronunciation, neutral tones and English/Korean interpretation. Separate spelling-format edits from linguistic corrections. The renderer accepts reading streams with or without punctuation tokens and gives punctuation no spoken annotation; joined erhua must not shift later readings. Cloze honours a validated explicit example focus across plain text, reading, feedback and Review. Invalid explicit spans stay out of fresh practice; an original saved blank conflicting with an explicit focus remains readable but is unavailable for retesting, without rewriting history. Legacy examples without explicit spans retain their first-match convention.
- Japanese: review difficulty for the selected reading and meaning, rather than raw kanji spelling frequency. Check okurigana, transitivity and the grammatical function used in the example. Adjectival uses of na-adjective stems should have concise adjectival equivalents and the learner adjective tag, preserving original source classifications in history. Prefer ordinary Korean vocabulary over literary labels, without removing useful technical precision. JLPT levels are editorial placements, not claims of an official exhaustive word list.

Primary examples are learner content; unreviewed `referenceExamples` remain research evidence. Review any additional examples and their aligned translations explicitly. Staging, publication and native installation are separate steps and must be reported accurately.

All presentations honour validated `retiredEntries` and `reviewInvalidations` package policies through the shared Review policy. German and Chinese record the study version on new questions and exclude invalidated targets, meaning choices and adjective-question nouns from active Review. Historical records remain stored; German archives a superseded record before recording a fresh corrected attempt, so old failures do not become the new question's wrong count. These policies do not approve any sense equivalence or transfer mastery to a new concept. Test baseline integration with `node scripts/verify-baseline-review-policy-browser.mjs`.

Run `node scripts/verify-chinese-reading-review-browser.mjs` to check reviewed punctuation-free and joined-erhua examples in phone/tablet layouts and both themes. It uses isolated browser storage and does not install draft packages into the user's app.

Run `node scripts/verify-chinese-cloze-focus-browser.mjs` for repeated-target checks across EN/KO, phone/tablet, light/dark and reading off/on, including saved-question retests. The public check uses an independently written fixture, not private draft corpus content.

Word List, Flashcards, Meaning Quiz, Word Input, Cloze, Sentence Scramble and Dictation remain the common defaults. Exercise Type is above the ordinary Filters, using the existing grammar selector layout. Custom typing/selection cards reuse the default vocabulary prompt, answer box, choices and bottom action bars. Japanese forms show the base word and reading, meaning, then the requested condition, like the default German form block.

This checklist records implemented functionality, not a claim that every contextual category has exhaustive questions for every dictionary word. Dictionary readings/forms and English countability have broad verified coverage; contextual particles, counters, collocations, phrasal verbs and contrasts still have smaller authored sets. Every published entry retains an explicit coverage status in the package source ledgers. The separate content expansion must preserve that distinction and cannot convert unreviewed source relations into graded questions.

Immutable package coverage ledgers describe the pools available when that package was released. New bundled reading-choice rules can create additional questions from the same verified metadata; they do not change the published package bytes or vocabulary IDs.
